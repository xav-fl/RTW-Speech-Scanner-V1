Decision letter and Inspector’s Report for a called-in application for:

outline planning application with all matters reserved, except for the primary means of access and road layout, for a phased mixed-use redevelopment involving the Demolition of existing buildings and structures including site preparation / remediation works

the development of residential units (Use Class C3), Class E uses including floorspace for retail Class E(a)), food/beverage and drinking establishments (Use Class E(b)), local services (Use Class E(c)), indoor sport / recreation / fitness (use Class E(d)), healthcare space (Use Class E(e)), creche / nursery uses (Use Class E(f)), office floorspace (Use Class E(g)(i)); a new multi-use stadium with associated business and leisure facilities (sui generis), hotel (Use Class C1), community uses floorspace (Use Class F2)

the phased redevelopment will include other sui generis uses; delivery of open space and significant realignment of the road network including the A226 Galley Hill Road / Stonebridge Road / Lower Road with hard / soft landscaping, car and cycle parking provisions, infrastructure works, ancillary and associated works.
